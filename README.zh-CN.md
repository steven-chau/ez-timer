# 简易计时器 — 免费在线运动及 HIIT 计时器

**一个免费、无需安装的间隔计时器，适用于运动、HIIT、Tabata、循环训练、拉伸、瑜伽及任何定时模式。** 在浏览器中运行。无需注册、无广告、无应用商店。现已支持运动记录追踪、日历热力图及 5 种语言。

## 为何选择简易计时器？

大多数运动计时器应用充满广告、需要注册，或将功能锁定在订阅付费之后。简易计时器与众不同：

- **真正免费。** 无广告、无账户、无付费墙。只是一个能用的计时器。
- **在浏览器中运行。** 支持手机、平板和电脑。无需安装任何东西。
- **离线使用。** 加载一次后，即使没有网络也能继续计时。
- **零依赖。** 纯 HTML、CSS 和 JavaScript。无框架、无追踪、无臃肿。

## 功能特色

### 快速设置运动
设置你的运动时间、休息时间、组数和准备倒计时——然后按开始。默认的 30 秒运动 / 10 秒休息 / 3 组让你在数秒内即可开始。

### 保存及整理模式
创建并命名你自己的模式（例如"早晨拉伸"、"Tabata 20/10"、"俯卧撑"）。保存在你的浏览器中——跨会话持续保存。**拖放**以重新排序你的模式，或一键**克隆**现有模式。

### 多语言支持
从菜单切换 **5 种语言**：English、廣東話、台灣中文、简体中文及日本語。所有界面文字即时更新。语音提示会根据所选语言使用对应地区的语音合成。

### 全屏计时器及视觉提示
- **动态背景颜色**按阶段变换：蓝色代表准备、红色代表运动、绿色代表休息
- **圆形进度环**一目了然显示剩余时间
- **大型倒计时数字**——在房间另一端也能看清
- **组数计数器**追踪你在模式中的进度

### 庆祝效果
当你的运动完成时，**彩纸炮**会从底部角落发射，带有色彩缤纷的粒子，并有**派对礼炮动画**放大向你祝贺。因为完成运动应该感到愉快。

### 运动记录及活动追踪
每次完成的运动都会自动保存，包括模式名称、日期、时间和持续时间。以两种模式查看你的记录：

- **详细视图**——按日分组的运动记录，以反向时间顺序排列，支持分页
- **日历热力图**——GitHub 风格的贡献图表，按日显示你的运动强度。绿色越深代表运动时间越长。

### 音效及语音提示
- 按地区特定的文字转语音，以你所选语言播报每个阶段
- 每个间隔最后 3 秒的倒计时哔声
- 运动阶段中的冥想颂钵音调
- 运动完成时的完成铃声

### 触控友好控制
- **播放 / 暂停**切换
- **向前 / 向后跳过**间隔
- **屏幕锁定**防止运动中途误触
- **向左 / 向右滑动**在手机上跳过间隔

### PWA 就绪
将其添加至手机主屏幕，像原生应用一样使用。包含 web manifest 并支持 Apple 的独立模式。

## 使用方法

1. **打开** `https://steven-chau.github.io/ez-timer`（任何设备皆可）
2. **设置你的模式**——调整运动时间、休息时间和组数
3. **按开始**——准备倒计时开始，然后你的运动随即开始
4. **保存你喜欢的模式**以便下次快速访问
5. **追踪你的进度**——在追踪记录视图中查看你的运动记录和日历热力图

就是这样。无需账户、无需安装、无广告。

## 在本地运行

克隆仓库并在任何浏览器中打开 `index.html`：

```bash
git clone https://github.com/steven-chau/ez-timer.git
cd ez-timer
open index.html  # 或在文件管理器中双击打开
```

使用开发服务器进行本地开发：

```bash
python3 serve.py
# → http://localhost:8080
```

## 技术

使用原生网页技术构建。无需构建步骤、无 `node_modules`、无框架：

- **HTML** — 语义化、无障碍的标记
- **CSS** — 使用 CSS 自定义属性、flexbox 和 grid 的响应式暗色主题
- **JavaScript** — 模块化状态机，配合 Web Audio API、Speech Synthesis、Canvas confetti 及 HTML5 Drag and Drop
- **localStorage** — 模式、运动记录、语言偏好和模式排序均在客户端持久保存

## 浏览器支持

适用于所有现代浏览器：Chrome、Firefox、Safari、Edge——桌面及手机均可。
