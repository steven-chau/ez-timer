# 簡易計時器 — 免費線上運動及 HIIT 計時器

**一個免費、無需安裝的間隔計時器，適用於運動、HIIT、Tabata、循環訓練、伸展、瑜伽及任何定時模式。** 在瀏覽器中運行。無需註冊、無廣告、無應用程式商店。現已支援運動記錄追蹤、日曆熱力圖及 5 種語言。

## 為何選擇簡易計時器？

大部分運動計時器 App 充斥廣告、需要註冊，或將功能鎖定在訂閱付費之後。簡易計時器與眾不同：

- **真正免費。** 無廣告、無帳戶、無付費牆。只是一個能用的計時器。
- **在瀏覽器中運行。** 支援手機、平板和電腦。無需安裝任何東西。
- **離線運作。** 載入一次後，即使沒有網路也能繼續計時。
- **零依賴。** 純 HTML、CSS 和 JavaScript。無框架、無追蹤、無臃腫。

## 功能特色

### 快速設定運動
設定你的運動時間、休息時間、組數和準備倒數計時——然後按開始。預設的 30 秒運動 / 10 秒休息 / 3 組讓你在數秒內即可開始。

### 儲存及整理模式
建立並命名你自己的模式（例如「早晨伸展」、「Tabata 20/10」、「伏地挺身」）。儲存在你的瀏覽器中——跨工作階段持續保存。**拖放**以重新排序你的模式，或一鍵**複製**現有模式。

### 多語言支援
從選單切換 **5 種語言**：English、廣東話、台灣中文、简体中文及日本語。所有介面文字即時更新。語音提示會根據所選語言使用對應地區的語音合成。

### 全螢幕計時器及視覺提示
- **動態背景顏色**按階段變換：藍色代表準備、紅色代表運動、綠色代表休息
- **圓形進度環**一目瞭然顯示剩餘時間
- **大型倒數數字**——在房間另一端也能看清
- **組數計數器**追蹤你在模式中的進度

### 慶祝效果
當你的運動完成時，**彩紙砲**會從底部角落發射，帶有色彩繽紛的粒子，並有**派對禮炮動畫**放大向你祝賀。因為完成運動應該感到愉快。

### 運動記錄及活動追蹤
每次完成的運動都會自動儲存，包括模式名稱、日期、時間和持續時間。以兩種模式檢視你的記錄：

- **詳細檢視**——按日分組的運動記錄，以反向時間順序排列，支援分頁
- **日曆熱力圖**——GitHub 風格的貢獻圖表，按日顯示你的運動強度。綠色越深代表運動時間越長。

### 音效及語音提示
- 按地區特定的文字轉語音，以你所選語言播報每個階段
- 每個間隔最後 3 秒的倒數嗶聲
- 運動階段中的冥想頌缽音調
- 運動完成時的完成鈴聲

### 觸控友善控制
- **播放 / 暫停**切換
- **向前 / 向後跳過**間隔
- **螢幕鎖定**防止運動中途誤觸
- **向左 / 向右滑動**在手機上跳過間隔

### PWA 就緒
將其新增至手機主畫面，像原生 App 一樣使用。包含 web manifest 並支援 Apple 的獨立模式。

## 使用方法

1. **開啟** `https://steven-chau.github.io/ez-timer`（任何裝置皆可）
2. **設定你的模式**——調整運動時間、休息時間和組數
3. **按開始**——準備倒數計時開始，然後你的運動隨即開始
4. **儲存你喜歡的模式**以便下次快速存取
5. **追蹤你的進度**——在追蹤記錄檢視中查看你的運動記錄和日曆熱力圖

就是這樣。無需帳戶、無需安裝、無廣告。

## 在本機運行

複製儲存庫並在任何瀏覽器中開啟 `index.html`：

```bash
git clone https://github.com/steven-chau/ez-timer.git
cd ez-timer
open index.html  # 或在檔案管理器中雙擊開啟
```

使用開發伺服器進行本地開發：

```bash
python3 serve.py
# → http://localhost:8080
```

## 技術

使用原生網頁技術構建。無需建置步驟、無 `node_modules`、無框架：

- **HTML** — 語義化、無障礙的標記
- **CSS** — 使用 CSS 自訂屬性、flexbox 和 grid 的響應式暗色主題
- **JavaScript** — 模組化狀態機，配合 Web Audio API、Speech Synthesis、Canvas confetti 及 HTML5 Drag and Drop
- **localStorage** — 模式、運動記錄、語言偏好和模式排序均在客戶端持久保存

## 瀏覽器支援

適用於所有現代瀏覽器：Chrome、Firefox、Safari、Edge——桌面及手機均可。
