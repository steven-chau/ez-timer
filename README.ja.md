# EZ タイマー — 無料オンライントレーニング & HIIT タイマー

**ワークアウト、HIIT、タバタ、サーキットトレーニング、ストレッチ、ヨガ、あらゆる時間制ルーティンのための無料・インストール不要のインターバルタイマーです。** ブラウザで動作します。サインアップ不要、広告なし、アプリストア不要。ワークアウト履歴トラッキング、カレンダーヒートマップ、5言語対応。

**[タイマーを開く →](https://steven-chau.github.io/ez-timer)**

## EZ タイマーを選ぶ理由

多くのワークアウトタイマーアプリは広告だらけで、サインアップが必要だったり、サブスクリプションで機能が制限されていたりします。EZ タイマーは違います：

- **完全無料。** 広告なし、アカウントなし、ペイウォールなし。ただ使えるタイマー。
- **ブラウザで動作。** スマートフォン、タブレット、デスクトップ対応。インストール不要。
- **オフライン対応。** 一度読み込めば、インターネットがなくてもタイマーは動き続けます。
- **依存ゼロ。** 純粋な HTML、CSS、JavaScript。フレームワークなし、トラッキングなし、無駄なし。

## 機能

### クイックワークアウト設定
ワーク時間、レスト時間、セット数、準備カウントダウンを設定して、スタートを押すだけ。デフォルトの 30秒ワーク / 10秒レスト / 3セットで、すぐに始められます。

### ルーティンの保存と整理
独自のルーティンを作成して名前を付けられます（例：「朝のストレッチ」「タバタ 20/10」「腕立て伏せ」）。ブラウザに保存され、セッションを超えて保持されます。**ドラッグ＆ドロップ**でルーティンを並べ替えたり、ワンクリックで既存のルーティンを**複製**したりできます。

### 多言語対応
メニューから **5言語** を切り替え：English、廣東話（広東語）、台灣中文（台湾華語）、简体中文（簡体字中国語）、日本語。すべてのUIテキストが即座に更新されます。音声アナウンスも選択した言語に適応し、ロケール固有の音声合成で行われます。

### 視覚的フィードバック付きフルスクリーンタイマー
- **動的な背景色**がフェーズごとに変化：準備は青、ワークは赤、レストは緑
- **円形プログレスリング**で残り時間が一目でわかります
- **大きなカウントダウン数字** — 部屋の反対側からでも読めます
- **セットカウンター**でルーティン内の現在位置を把握

### 達成エフェクト
ワークアウトが終了すると、**紙吹雪キャノン**が下部の隅からカラフルなパーティクルを発射し、**クラッカーアニメーション**が拡大表示されて祝福します。ワークアウトを終えた達成感を気持ちよく味わえるように。

### ワークアウト履歴＆アクティビティトラッキング
完了したワークアウトはすべて、ルーティン名、日付、時刻、時間とともに自動的に保存されます。履歴は2つのモードで表示できます：

- **詳細ビュー** — 日付ごとにグループ化されたワークアウトを逆時系列で表示、ページネーション付き
- **カレンダーヒートマップ** — GitHub スタイルの貢献グラフで、日ごとのワークアウト強度を表示。緑が濃いほどセッションが長いことを示します

### 音声＆オーディオアナウンス
- ロケール固有のテキスト読み上げが、選択した言語で各フェーズをアナウンス
- 各インターバルの残り3秒のカウントダウンビープ音
- ワークフェーズ中の瞑想ボウルのゴング音
- ワークアウト完了時のチャイム音

### タッチ操作対応
- **再生 / 一時停止** 切替
- **前方 / 後方スキップ**でインターバル間を移動
- **画面ロック**でワークアウト中の誤タップを防止
- **左右スワイプ**でモバイル時のインターバルスキップ

### PWA対応
スマートフォンのホーム画面に追加して、ネイティブアプリのように使用できます。ウェブマニフェストを含み、Apple のスタンドアローンモードにも対応。

## 使い方

1. **開く** `https://steven-chau.github.io/ez-timer`（任意のデバイスで）
2. **ルーティンを設定** — ワーク時間、レスト時間、セット数を調整
3. **スタートを押す** — 準備カウントダウンが始まり、ワークアウトが開始されます
4. **お気に入りのルーティンを保存**して次回すぐにアクセス
5. **進捗を追跡** — トラックレコードビューでワークアウト履歴とカレンダーヒートマップを確認

以上です。アカウント不要、インストール不要、広告なし。

## ローカルでの実行

リポジトリをクローンして、任意のブラウザで `index.html` を開きます：

```bash
git clone https://github.com/steven-chau/ez-timer.git
cd ez-timer
open index.html  # またはファイルマネージャーでダブルクリック
```

開発サーバーを使ったローカル開発：

```bash
python3 serve.py
# → http://localhost:8080
```

## 使用技術

バニラのウェブ技術で構築。ビルドステップ不要、`node_modules` 不要、フレームワーク不要：

- **HTML** — セマンティックでアクセシブルなマークアップ
- **CSS** — CSS カスタムプロパティ、flexbox、grid を使用したレスポンシブダークテーマ
- **JavaScript** — Web Audio API、Speech Synthesis、Canvas confetti、HTML5 Drag and Drop を備えたモジュラー型ステートマシン
- **localStorage** — ルーティン、ワークアウト記録、言語設定、ルーティン順序をクライアントサイドで永続化
